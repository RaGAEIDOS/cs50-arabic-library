# مكتبة CS-50 بالعربية

منصة تعليمية شاملة لتعلم علوم الحاسوب والمواد الأساسية.

## المميزات

- 📚 أكثر من 50 مورد تعليمي
- 🎯 أقسام منفصلة لكل مادة
- 🔖 نظام مفضلة لحفظ الموارد
- 📊 تتبع التقدم التعليمي
- 🔍 بحث فوري في الموارد
- 💾 حفظ تلقائي للبيانات
- 🎨 تصميم عصري وسهل الاستخدام

## الأقسام

- **CS-50**: محاضرات Harvard的基础CS课程
- **الرياضيات**: جبر، حساب التفاضل، رياضيات منفصلة
- **الفيزياء**: ميكانيكا، كهرباء، بصريات
- **الكيمياء**: كيمياء عامة وعضوية
- **الإحصاء**: إحصاء وصفي واستنتاجي
- **البيولوجيا**: أحياء عامة ووراثة

## الاستخدام

1. افتح التطبيق في المتصفح
2. اختر القسم المطلوب من الشريط الجانبي
3. استخدم البحث للعثور على موارد محددة
4. اضغط على النجمة لحفظ الموارد المفضلة
5. تتبع تقدمك في قسم "التقدم"
